## 二、⚠️ 必须处理的问题：姓名重复

证书上印的是 **"Haiyu Li Li"** —— 姓 `Li` 出现了两次。

**为什么会这样**：Unstop 的证书是拿报名时填的姓和名拼出来的。你报名时
First Name 填了 `Haiyu`、Last Name 填了 `Li Li`（或者反过来填成了
`Haiyu Li` + `Li`），系统就拼出了 `Haiyu Li Li`。

**为什么必须改**：
- Erasmus+ 联合培养申请表要求姓名与护照/成绩单完全一致
- 学校初审会核对，「Li Li」这种一眼假的重复会让整份材料显得不严谨
- 你的成绩单上是 `李海钰`，护照上大概率是 `LI HAIYU` 或 `HAIYU LI`
- 证件和官方证书对不上，是最容易被要求补材料的地方

**正确写法应该是**：`Haiyu Li`（姓 Li，名 Haiyu）

- Email（`asylviaofmine@outlook.com` vs `asylviaofmine@gmail.com` —— GitHub 提交用的是 gmail，简历用的是 outlook）
- College / Department
- Graduation year

> 📌 邮箱那个值得统一。Unstop 账号邮箱如果填的是 gmail，而你要投的公司
> 简历上写 outlook，虽然不算错，但**用同一个邮箱更干净**。
